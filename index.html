HRMS Schema (`demo_hrms`)

8 relational tables supporting leave entitlement, attendance, approval hierarchies, and company calendars:

  • users — User credentials, roles (Admin, Manager, Employee), designations, reporting lines.
  • leave_types — Sick Leave (SL), Casual Leave (CL), Paid Privilege Leave (PL), WFH.
  • leave_balances — Total, utilized, and remaining quota balances.
  • leave_applications — From/to dates, reason, status (Pending, Approved, Rejected), manager remarks.
  • official_holidays — Calendar holidays for 2026.
  • optional_holidays — Optional festival holidays.
  • user_optional_holidays — Employee-selected optional days.
  • attendance_logs — Daily check-in timestamps and punch audit records.

Clientele Schema (`demo_clientele`)

Structured category and brand catalog system with audit logging:

  • clientele_users — Admin portal authentication and access levels.
  • categories — Industry verticals (Automotive, BFSI, Healthcare, Technology, Retail, etc.).
  • clients — Brand names, industry category mapping, website URLs, logo paths, display ordering.
  • audit_logs — Activity audit log of client updates and admin operations.

PMS Schema (`demo_pms`)

Full MVC project delivery and team timesheet schema with 22 tables:

  • users — Authentication, permissions, and roles (Admin, Project Manager, Member).
  • clients — Fictional enterprise client accounts.
  • projects — Multi-client projects, budgets, deadlines, and project health metrics.
  • phases — Project milestone phases (Discovery, Wireframes, UI Design, QA, Delivery).
  • tasks — Granular deliverable items, priorities, due dates, assignee IDs, and Kanban status.
  • task_assignees — Multi-assignee support matrix.
  • work_logs — Hourly work logs, task links, timesheet notes, and approval records.
  • custom_fields — Extensible metadata definitions.
